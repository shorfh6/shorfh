# رصد إشعارات عكاظ عبر RSS — مفعّل محليًا

في 2026-10-29 أكد المالك طلب متابعة عكاظ آليًا، واعترض على تكرار سؤال الترخيص لقراءة RSS. أعيد التحقق من صفحة الخدمة الرسمية التي تتيح الاشتراك المجاني في الأخبار والعناوين والمختصرات وروابط المصدر. أُجيز تنفيذ قارئ **إشعارات اكتشاف** محدود بذلك؛ لا يشكل ترخيصًا لإعادة توزيع المتون أو صور الناشر، ولا اعتمادًا تحريريًا تلقائيًا.

## التنفيذ والتحقق

- `rss-discovery.mjs`: جلب نقاط RSS الخمس المثبتة فقط، بمهلة وTLS الافتراضي ورفض التحويلات، وحد استجابة 2MiB. تحليل XML بمكتبة `fast-xml-parser` ذات إصدار مثبت في lockfile، مع رفض DTD/custom entities، وتحقق روابط المقالات وتواريخها.
- يحتفظ بعنوان ورابط وتاريخ المصدر ووقت الرصد وهوية URL ثابتة فقط؛ لا يحفظ description/content أو الصور. تعامل هذه البيانات كمدخل خارجي خامل لا تعليمات.
- `watch-okaz-rss.mjs`: حفظ دائم محلي وقفل حصري وكتابة ذرية، وحد 300 ثانية، ومنع التكرار عبر الأقسام وإعادة التشغيل. تظل حالة الإشعار discovered ولا يصبح خبرًا أو اعتمادًا. البيانات القديمة أو غير المؤرخة غير مؤهلة للاختيار كخبر حديث.
- السجل في `.raad-local/okaz-rss-reader/`، متجاهل في Git. سعة 10000 إشعار؛ بلوغها يفشل بوضوح ويحتاج أرشفة مدروسة بدل حذف الهوية وإعادة اكتشاف القصص على أنها جديدة.
- أول قراءة محفوظة عند **2026-10-29T13:57:36.813Z**: 250 إشعارًا فريدًا من خمسة أقسام، صفر فشل وصفر مرفوض، و**صفر خبر أُنشئ أو نُشر بواسطة القارئ**.
- مهمة Windows `Shurfa-Okaz-RSS-Discovery-v1` ثُبتت كل خمس دقائق بحساب المستخدم التفاعلي المحدود، مع منع تشغيل نسختين ومهلة ثلاث دقائق. نجح استدعاء المهمة بنتيجة 0. الاستدعاء المباشر الأول أثبت الجلب؛ الاستدعاء التالي المبكر يرجع not_due. لا يُعد ذلك إثبات دورة نشر أو وصول خبر جديد في موعد لاحق.
- نجحت 11 حالة جديدة تشمل استمرار الهوية، القفل، فشل قسم، وحظر الروابط الخارجية وXML الخطير والحجم والتواريخ. أحدث suite **523 حالة ناجحة**، وفحص TypeScript نجح.

## التشغيل والإيقاف

المهمة المحلية تعمل ما دام جهاز Windows يعمل والمستخدم مسجل الدخول؛ **ليست خدمة سحابية مستقلة تعمل عند إغلاق الجهاز**. لا تُنسخ مفاتيح الويب أو بيانات المتصفح إلى القارئ. لتعطيلها استخدم Task Scheduler وعطّل اسم المهمة المحدد فقط.

لتشغيل قراءة صريحة بعد التحقق من المسار:

```text
node scripts/raad/watch-okaz-rss.mjs --directory <absolute-existing-private-directory> --execute-reader
```

## المتبقي للطلب الكامل

ربط الإشعارات باختيار الخبر والتحقق من المصدر والتحرير الأصيل وSEO وتوليد/اختيار صورة ومراجعتها ثم اعتماد snapshot وإضافتها إلى طابور النشر. هذه الدورة **غير موصولة بالقارئ حتى الآن**. عامل المعتمد الإنتاجي المنفصل يعمل كل خمس دقائق، والمادة 54 منشورة ومتحقق منها؛ لا يجوز عرض حالة القارئ وكأن كل جديد عكاظ يُنشر تلقائيًا. `config/raad/rss-reader.json` يصف الرصد المستقل، بينما runtime.json وعقد sources.json المغلقان يظلان مرجع محاكاة المراحل ونطاق النصوص والصور السابق.
