# سجل المصادر — شُرفة / RAAD

## متابعة تقنية 2026-10-29

حُلّ قالب RSS عبر طلب sections المعلن في صفحة الخدمة نفسها: `/api/pb/sections?widget_id=23551` يعيد الأقسام، والروابط من نمط `/rssFeed/<np_section_id>`. جُلب `/rssFeed/1` يدويًا وتحقق RSS 2.0 بروابط وpubDate ذات منطقة زمنية صريحة. تحفظ لقطة endpoints وحالة التحقق فقط في `config/raad/source-discovery.snapshot.json`، دون نسخ المتون أو الصور إلى المستودع.

تشرح صفحة الخدمة استعمال News Reader وعناوين/ملخصات/روابط مجانًا. أعيدت قراءة الشروط، ولا يزال القسم 15 يشترط موافقة خطية لإعادة الاستخدام العام أو التجاري والمواد المشتقة. التغذية الفعلية تحمل أوصافًا طويلة قد تحتوي متنًا، فلا تُعامل كتراخيص لإعادة نشره. لم تُفتح أذونات السجل أو تُركب جدولة جمع عكاظ بهذا التحقق. موافقة اختيار عكاظ التحريرية السابقة مكتملة؛ الحاجة المتبقية تخص نطاق الاستعمال المصرح، لا إعادة السؤال نفسه.

## قرار المالك وحدوده — 2026-10-25

تعليمات المالك الصريحة: «https://www.okaz.com.sa/ اعتمد على موقع عكاظ ايضا».
يسجل `config/raad/sources.json` عكاظ مصدرًا للرجوع التحريري فقط:
`ownerApproval: editorial-only` و`approvalScope: editorial-reference-only` و`approvedBy: owner`.
هذه موافقة اختيار مصدر من المالك، وليست إذنًا من الناشر بالجمع الآلي أو إعادة نشر المقالات أو استعمال الصور.

تبقى `automatedCollection` و`articleRepublication` و`imageReuse` جميعها `false`،
و`rightsStatus: permission-pending`. لا إعادة نشر آلية للنصوص أو الصور، ولا تشغيل حي أو مسار إدخال أخبار مصرح به في هذه المرحلة.
إعداد التشغيل يبقى جافًا، والنشر الحي والمجدول معطلين؛ قبول بنية السجل لا ينفذ جمعًا أو نشرًا ولا يمنح صلاحيات وكلاء أو أدوات.

## مخطط مغلق ومراجعة لازمة

يبدأ `validateSourceRegistry` بـ`assertNoSecrets` ثم يقبل حالتين فقط تحت `raad.contract/1`:

- الحالة القديمة للـfixtures: `ownerApproval: pending` و`sources: []`.
- البيان التحريري المراجع الحالي: مصدر واحد، `okaz` / `عكاظ`، بالقيم والروابط والتاريخ المثبتة في السجل.

كل الحقول مطلوبة، والمفاتيح الإضافية مرفوضة في السجل والمصدر و`discovery` و`policy`.
الروابط الثلاثة تطابق نصيًا العناوين المراجعة أدناه؛ لا أصول بديلة أو مضيفات خاصة أو بيانات دخول أو معاملات استعلام أو شذرات URL.
لا يقبل السجل حقول تعليمات أو أدوات أو صلاحيات. لا يمكن تفعيل الجمع أو إعادة النشر أو الصور، أو ترقية `feedVerified`، بتغيير JSON وحده؛ أي توسعة تحتاج تنفيذًا مراجعًا وأدلة الحقوق والموافقات المناسبة.
هذه قيود بنيوية وليست إثبات هوية أو ترخيص أو تحققًا من صحة الأخبار.

- المنطقة الزمنية غير مذكورة؛ لا تحويل إلى UTC ولا اختلاق إزاحة زمنية.
- هذه بيانات وصفية بحثية فقط؛ لم يُنسخ متن المقال ولا صورة، ولا تمثل خبرًا تحقق منه وكلاء الأخبار أو مادة معتمدة للنشر.

## وكالة الأنباء السعودية (SPA): مرشح مراجع، غير مسجل

SPA مرشح جرت مراجعته سابقًا، وليس مصدرًا معتمدًا من المالك في هذا السجل.
أظهرت بيانات HTML المضمنة `__NEXT_DATA__` ثمانية عناصر `mainNews` بتاريخ 2026-10-25،
مع `content: null` و`subtitle: null`؛ لا تثبت هذه البيانات وجود متن متاح أو مسار إدخال أخبار مصرح به.
الشروط المضمنة تمنع الاستخراج الآلي دون إذن كتابي، ولم يثبت RSS أو API صريح.
يبقى الجمع الآلي محجوبًا، ولا تضاف SPA إلى المصادر النشطة أو تُستنتج موافقة المالك عليها. لم تُجر طلبات SPA إضافية في هذه المهمة.
