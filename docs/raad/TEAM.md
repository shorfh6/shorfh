# فريق رعد — الأسماء الحالية

اختيرت أسماء شخصية للفريق استجابة لطلب المالك تغيير المسميات السابقة.

| الاسم المستخدم في الحديث والتقارير | المسؤولية | معرّف المهمة |
| --- | --- | --- |
| سيف | اكتشاف الأخبار وجمع مصادرها | `al-rasid` |
| عمر | التحقق من الحقائق والأدلة | `al-muhaqqiq` |
| راكان | التحرير العربي وSEO | `al-muharrir` |
| ريان | الصور المصغرة والوسائط وحقوقها | `al-musawwir` |
| حازم | المراجعة النهائية والاعتماد | `al-mutamid` |
| نايف | فحص حزمة النشر ونتيجته | `al-nashir` |
| فهد | الأمن والصلاحيات والاعتمادية | `al-haris` |
| سلمان | الأداء والتكلفة والتقارير | `al-muraqib` |

رعد (`raad`) مدير الفريق ونقطة التنسيق. هذه أسماء عرض وهوية محادثة للوكلاء؛ معرّفات عقود المهام ثابتة، والسجلات السابقة تحتفظ بالهوية التي صدرت بها وقت تنفيذها. تغيير الاسم ليس توسيعًا للصلاحيات ولا دليل تشغيل دائم. يلزم إعادة تشغيل OpenCode لتحميل التعريفات المحدّثة في الواجهة؛ العمليات الجديدة تحمل تعريفاتها عند البدء.
