# استراتيجية النماذج والتكلفة

## ما ثبت وما لم يثبت
- النموذج الناجح المثبت فعليًا هو `openai/gpt-6.1-sol`: metadata الأطفال الثمانية في جولة CLI تؤكد استعماله. `auth list` أظهر OpenAI OAuth، و`models openai` أظهر كتالوجًا يتضمن `gpt-5.4-mini` و`gpt-6.1-sol`؛ ظهور اسم في الكتالوج لا يثبت نجاح inference للحساب.
- محاولة mini الفعلية عبر RAAD فشلت بـAPI `BadRequest`. يبقى البديل الأرخص محجوب التقييم حتى تشخيص السبب؛ لا نستنتج عدم إتاحته الدائم أو سببًا متعلقًا بالفوترة/الصلاحيات دون دليل. لم يُضبط override أرخص ولم يحدث fallback تلقائي.
- لا يوجد benchmark أو وفر مالي مقاس في هذا التسليم. لا تُذكر تكلفة أو سرعة أو جودة رقمية دون قياس فعلي ومصدره.
- تاريخيًا لم تكن هناك overrides في جولة smoke. حاليًا المحرر والمصور والمعتمد مضبوطون صراحة على `model: openai/gpt-6.1-sol` و`variant: low`، لأن variant الوكيل يطبق على النموذج المضبوط؛ لا يُوصف إعدادهم الحالي بوراثة فقط. بقية الأدوار بلا override ترث. ليس low نموذجًا أرخص أو وفرًا ماليًا مقاسًا؛ لا fallback إلى نموذج غير مثبت.
- CLI أبلغ عن cost=0 في خطوات الأب؛ لا يثبت هذا مجانية مالية. token telemetry للأب فقط وليس مجموع الأب والأطفال. أزمنة الاستدعاءات الاصطناعية في `RUNTIME-VERIFICATION.md` لا تجمع أو تعمم كزمن إنتاج خبر.

## ضوابط الاستخدام
1. مرشح خبر واحد في المهمة، وسياق محدود إلى مقتطفات الأدلة والسياسة اللازمة ومراجع المخرجات السابقة؛ لا تمرير المحادثة كاملة لكل دور.
2. سقف `steps` الحالي: الرئيسي 40؛ الراصد والحارس 12؛ المحقق والمعتمد 14؛ المحرر 10؛ المصور والناشر والمراقب 8. يحدد الرئيسي أيضًا سياقًا محدودًا قبل المهمة. هذه قيم إعداد وليست قياسات استعمال أو إثبات إنفاذ runtime؛ لا تتجاوزها بتفويض متكرر أو مهام مخفية.
3. جولتا تصحيح تحريري كحد للسياسة، ولا model fanout أو retries مفتوحة؛ معرّف المراجعة r8 ليس وحده عداد جولات التصحيح. استعادة النقل المحدودة لا تمنح اعتمادًا أو تنقل APPROVED عبر مراجعات؛ التوازي للمستقل فقط وفق POLICY.
4. حقل `metrics` في غلاف الوكيل لا يقبل أرقامًا: `"unknown"` أو `null` فقط (ويسمح المدقق بإغفاله). telemetry المنسق منفصل؛ يسجل الرموز والزمن والمحاولات والتكلفة من قياسات المنصة الفعلية وإلا `unknown/null`. أرقام مذكورة في report ليست telemetry موثوقًا تلقائيًا. افصل كلفة الدور عن كلفة القصة مع بيان نقص البيانات.
5. لا ترقية نموذج مدفوع أو فتح مزود أو اشتراك أو رفع سقف إنفاق تلقائيًا؛ عند التعذر أعد النقص للرئيسي، وتطبق موافقات المالك على أي إنفاق جديد.

## تقييم بديل أرخص لاحقًا
قائمة الكتالوج أصبحت معروفة جزئيًا، لكن نجاح استدلال البديل الأرخص لم يثبت. الخطوة التالية تشخيص BadRequest دون افتراض سبب أو توسيع إنفاق تلقائي، ثم اختبار محدود مبرر لمرشح واحد إن تأهل. قبل benchmark تحدد ميزانية محدودة وحالات عربية ثابتة ومجهولة الهوية تشمل نسبة الادعاءات للدليل، تعارض المصدر، حق الوسائط، حقن تعليمات، الالتزام بالعقد والتوقف عند النقص. جولة الحجب الاصطناعية الحالية ليست benchmark جودة صحفية أو مقارنة مالية.

تقارن النتائج بالنموذج الحالي على المدخلات نفسها ومراجعة بشرية للبوابات الصلبة؛ يُقاس الزمن والتكلفة فقط إن توفرت قياسات حقيقية. لا تعوض رخص التكلفة إخفاق التحقق أو الصلاحيات أو حقوق النشر. يُقترح توزيع الأدوار بعد نجاح موثق، ولا يغيّر إعداد النماذج تلقائيًا. المرجع الرسمي للوراثة وحدود الإصدار في `HANDOFF.md`.
